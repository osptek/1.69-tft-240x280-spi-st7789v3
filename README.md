# 1.69 寸 240×280 TFT SPI 模组（ST7789V3）资料与示例

**English：** [`README_EN.md`](README_EN.md)

---

> 本仓库提供该模组的 **ESP-IDF 示例工程**。数据手册与规格书待后续补充至 `docs/`。

## 产品概要

| 项目 | 说明 |
|:--|:--|
| 模组规格 | 1.69 英寸 **TFT**（IPS），分辨率 **240×280** |
| 接口 | **SPI** |
| 驱动芯片 | **ST7789V3** |
| 规格标识 | 产品资料中常用 **`1.69-tft-240x280-spi-st7789v3`** 表示本规格 |
| 相近规格 | **ST7789**（含触摸与分测工程）见 **`1.69-tft-240x280-spi-st7789`**，驱动型号不同、独立维护 |
